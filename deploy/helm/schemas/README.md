# ServiceMonitor validation schema

`servicemonitor.json` is the v1 OpenAPI schema extracted from the official Prometheus Operator **v0.87.1** [ServiceMonitor CRD](https://github.com/prometheus-operator/prometheus-operator/blob/v0.87.1/example/prometheus-operator-crd/monitoring.coreos.com_servicemonitors.yaml), under its [Apache-2.0 licence](https://github.com/prometheus-operator/prometheus-operator/blob/v0.87.1/LICENSE). Descriptions/titles are removed and generic Kubernetes metadata is accepted; the CRD's spec validation rules are retained. It lets optional ServiceMonitor renders pass kubeconform without skipping unknown resources. No CRD is installed by the CivicOps chart. The owner must install the matching Prometheus Operator CRD and configure its collector service and namespace.
