## Reproduce locally

```bash
export PATH=$HOME/.dotnet:$HOME/.local/bin:$PATH
export DOTNET_CLI_TELEMETRY_OPTOUT=1 DOTNET_NOLOGO=1
dotnet build -c Release --no-incremental
./scripts/security_dependencies.sh
./scripts/sbom.sh "$TMPDIR/sbom.cdx.json"
bash -n scripts/*.sh
"$TMPDIR/bin/actionlint" -color=false .github/workflows/*.yml
```

`security_dependencies.sh` requires Python 3, Git, .NET, npm and advisory-feed connectivity, including the vendored map-package check. It preserves the NuGet and Git-tracked npm gates, then validates the local map manifest, creates an exact-version `package.json` and lock under the platform temporary directory, and runs `npm audit --audit-level=low` with `https://registry.npmjs.org` explicitly selected. Before the audit, it checks that npm resolved exactly the two reviewed packages and that their versions, official archive URLs and SHA-512 integrity match the manifest. No lifecycle scripts run; npm's cache also remains under that temporary directory. Missing/invalid provenance, advisory findings and failed queries fail the gate. [Eleven offline guard tests](../../scripts/test_map_vendor_manifest.py) run in the same gate, covering pinned names/versions, unsafe sources/paths, licence retention, changed files, symlink escape, duplicate JSON fields, temporary-output enforcement and rejection of mismatched registry digests or archive hosts. All eleven passed locally.

`sbom.sh` requires .NET 10, Python 3, a writable temporary directory and package connectivity for its pinned CLI/restore. It supports an output path argument; CI/verification should generate into temporary storage to keep the working tree clean. Update the committed inventory intentionally after dependency or browser-bundle changes. Both scripts use the same [map-manifest validator](../../scripts/map_vendor_manifest.py). No new application configuration variables are introduced by these scripts.

The map inventory reads the committed [vendor manifest](../../products/civicops/wwwroot/vendor/map-vendors.json): Leaflet **1.9.4** (BSD-2-Clause) and Leaflet.markercluster **1.5.3** (MIT), with the clustering package's dependency on Leaflet recorded. It verifies all **13** shipped assets/licence files before accepting the manifest. A changed file, path outside the vendor directory, unreviewed distribution URL, runtime CDN flag, invalid tarball integrity or duplicate component fails generation. Eight isolated local fixtures passed: a valid manifest and byte-identical repeat, plus rejection of those six invalid cases. Regeneration preserved all **65** previous components and their dependency edges, including all **62** NuGet components; the two map libraries are the only additions. The heat layer is CivicOps canvas code and introduces no third-party package.

The committed SBOM omits timestamps/random serial numbers for stable diffs. It is an inventory of **resolved package/bundle declarations**, not an assertion that the entire host has no vulnerabilities. It excludes the shared .NET runtime, operating-system/container packages, development CLI tool dependencies, nested CDN/worklet bundle graphs, hosted model weights and provider services. Add container/runtime/model inventories and deployment provenance before an enterprise release. Version/SRI-pinned optional browser bundles remain disabled when voice is unconfigured; their live microphone/CDN behavior was not exercised by this offline round.

All retained versions must still be monitored and upgraded when advisories or support windows change. The local advisory results describe the feeds at verification time, not future safety. Review [ASVS](ASVS_L2.md) and [STRIDE residual risks](THREAT_MODEL.md) alongside the CI checks.
